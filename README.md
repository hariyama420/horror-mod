# Horror Mode

Хоррор-мод для **Minecraft 1.20.1 · Forge 47.3.0+ (ветка 47)**. Добавляет тревожные сообщения, внезапную темноту, атмосферные звуки и встречи с двумя незнакомцами. События происходят случайно, а у каждого игрока свои таймеры.

## Установка

1. Установите Minecraft 1.20.1 и Forge 47.3.0 или новее из ветки 47.
2. Поместите собранный `horrormode-1.0.0.jar` в папку `mods`.
3. Запустите игру и войдите в мир.

Для сетевой игры мод нужен **на сервере и у всех игроков**. Используйте одну и ту же сборку на обеих сторонах: несовместимые версии сетевого протокола не смогут подключиться. Инструкция по сборке из исходников приведена ниже.

## Возможности

Автоматические события работают для живых игроков в выживании и приключении во всех измерениях. Интервалы указаны для настроек по умолчанию при 20 TPS.

| Событие | Интервал | Что происходит |
| --- | --- | --- |
| Сообщение | 40–80 секунд | Тёмно-красный текст с нечитаемыми символами |
| Темнота | 50–90 секунд | Эффект Darkness на 8 секунд |
| Незнакомец | 180–300 секунд | NPC появляется рядом и преследует игрока |
| Наблюдатель | 50–90 секунд | Неподвижный NPC следит за игроком |
| Случайный звук | 90–180 секунд | Один из 13 пользовательских звуков |

Таймеры независимы: события могут совпадать и происходить в разное время у разных игроков. Для NPC интервал определяет попытку появления. Если подходящего места нет или такой NPC уже находится рядом с той же целью, попытка пропускается.

### Сообщения

В наборе десять равновероятных вариантов:

- Шесть русских фраз с нечитаемыми символами по краям.
- Четыре сообщения полностью из нечитаемых символов длиной 12, 24, 40 и 64 символа.

Все варианты доступны автоматически и через `/horror message`. Русский резервный текст позволяет показывать фразы даже при другом языке игры.

### Незнакомец и наблюдатель

**Незнакомец** появляется в 5–9 блоках со звуком, преследует выбранного игрока и исчезает после одного удара либо примерно через 30 секунд. По умолчанию удар снимает 70% текущего здоровья: например, 20 HP превращаются в 6 HP. Удар обходит броню и поглощение, не отбрасывает и оставляет минимум 1 HP; здоровье ниже 1 HP не изменяется. На мирной сложности незнакомец удаляется игрой.

**Наблюдатель** появляется в 12–24 блоках в видимом месте, стоит и поворачивается к игроку. Он молчит и не атакует. Исчезает через 20 секунд, при получении урона или приближении любого живого игрока вне режима зрителя на 4 блока. Работает и на мирной сложности.

Оба NPC используют модель игрока и пользовательский скин. Встреча заканчивается при выходе, смерти, смене измерения, переходе цели в режим зрителя или удалении цели более чем на 64 блока. Незнакомец также исчезает при переходе цели в творческий режим. После загрузки чанка прежние встречи не возобновляются.

### Звуки и mood

Случайные звуки слышит только выбранный игрок; их громкость регулируется категорией «Окружение». В набор входят `1.ogg`–`9.ogg` и четыре `morsecodemagic-audio*.ogg`, каждый с одинаковой вероятностью. Звук появления незнакомца `output.ogg` относится к категории «Враждебные существа».

Показатель mood в F3 накапливается независимо от освещения. По умолчанию скорость увеличена в четыре раза относительно задержки mood биома: для стандартной задержки цикл занимает примерно 75 секунд. При заполнении звучит атмосферный звук биома, затем счётчик сбрасывается. В биомах без mood используется пещерный звук. Фоновые звуки биомов сохраняются.

## Команды

Команды требуют **уровень прав 2 или выше**: OP на сервере или включённые читы в одиночной игре.

| Команда | Действие |
| --- | --- |
| `/horror message [players]` | Отправить случайное хоррор-сообщение |
| `/horror darkness [players]` | Наложить Darkness |
| `/horror sound [players]` | Проиграть случайный пользовательский звук |
| `/horror npc [players]` | Вызвать незнакомца |
| `/horror watcher [players]` | Вызвать наблюдателя |
| `/horror mood [players]` | Заполнить mood и вызвать атмосферный звук на следующем тике |

`[players]` — необязательный ник или селектор. Без аргумента команда действует на исполнителя. В серверной консоли цель обязательна.

```mcfunction
/horror message @a
/horror watcher PlayerName
/horror sound @p
```

Мёртвые игроки и зрители исключаются. Незнакомца можно вызвать только для игрока в выживании или приключении; остальные команды доступны и для целей в творческом режиме. Если NPC не удалось создать, исполнитель получает сообщение о причине.

## Настройки

Конфигурация создаётся отдельно для каждого мира:

- Одиночная игра: `saves/<мир>/serverconfig/horrormode-server.toml`.
- Выделенный сервер: `<мир>/serverconfig/horrormode-server.toml`.

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `automaticEvents` | `true` | Включает автоматические события; команды и накопление mood работают независимо |
| `darknessSeconds` | `8` | Длительность Darkness в секундах |
| `npcDamagePercent` | `70.0` | Процент текущего здоровья, снимаемый незнакомцем |
| `moodSpeedMultiplier` | `4.0` | Множитель скорости накопления mood |

Интервалы задаются полями `minimumSeconds` и `maximumSeconds` в разделах `events.message`, `events.darkness`, `events.attacker`, `events.watcher` и `events.sound`. Допустимый диапазон — от 3 до 3600 секунд. Если минимум больше максимума, значения используются в обратном порядке.

Перед ручным редактированием закройте мир или остановите сервер. При обновлении сохранённые интервалы не заменяются новыми значениями по умолчанию; при необходимости измените их по таблице событий выше.

## Сборка из исходников

Требуется **JDK 17**. Gradle Wrapper включён в репозиторий; при первой сборке потребуется доступ к сети для загрузки Gradle и зависимостей.

Linux / macOS:

```bash
./gradlew build
```

Windows:

```powershell
.\gradlew.bat build
```

Готовый мод: `build/libs/horrormode-1.0.0.jar`.

### Запуск и проверки для разработки

```bash
./gradlew runClient
./gradlew runServer
./gradlew healthDrainCheck
```

Для сервера разработки требуется принять EULA в `run/eula.txt`. В Windows используйте `gradlew.bat` с теми же задачами.

Проверка граничных случаев урона `healthDrainCheck` включена в задачу `check` и выполняется при сборке. Для ручной проверки войдите в выживание, вызовите события командами и проверьте их автоматическое появление. В сетевой игре проверьте выбор целей, независимость таймеров и права доступа к командам.

Тексты сообщений находятся в [ru_ru.json](src/main/resources/assets/horrormode/lang/ru_ru.json), звуки — в [assets/horrormode/sounds](src/main/resources/assets/horrormode/sounds), настройки по умолчанию — в [HorrorConfig.java](src/main/java/org/hariyama/horrormode/HorrorConfig.java).
